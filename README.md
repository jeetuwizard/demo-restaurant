# Masala Lane Kitchen — demo restaurant website

A demo website for a **fictional** Delhi restaurant, built by [PrimeCraft Labs](https://jeetuwizard.github.io/).

**Live demo:** https://jeetuwizard.github.io/demo-restaurant/

## Features
- Full menu with categories, veg/non-veg markers and prices
- Add-to-order cart with a running total
- One-tap WhatsApp ordering with the order message pre-filled (shown as a preview in this demo)
- Food gallery, reviews, opening hours and directions
- Mobile-first, fast, accessible; static site hosted free on GitHub Pages

## Tech
Next.js (static export) · React · TypeScript · Tailwind CSS

## Run locally
```bash
npm install
npm run dev
```
Open http://localhost:3000/demo-restaurant/
