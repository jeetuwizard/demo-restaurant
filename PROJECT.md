# Concept project: Masala Lane Kitchen (restaurant website)

- **Type:** Concept project (our own showcase, built like a client site)
- **Owner:** Jitender (PrimeCraft Labs)
- **Status:** rebuilt with real photos and a working WhatsApp order flow (2026-10-26)
- **Showable:** yes (label it "Concept project", never as a real client)
- **Stack:** Next.js 16 (static export, basePath from brand.json), Tailwind CSS 4, TypeScript
- **Live link:** https://primecraftlabs.github.io/masala-lane-kitchen/ (GitHub repo `masala-lane-kitchen`; local folder keeps the name `demo-restaurant`)

## Brief
A complete website for a North Indian restaurant, built to the standard we'd deliver to a paying client:
real food photos, full menu with prices, add-to-order cart, order sent on WhatsApp, gallery, hours and directions.
Masala Lane Kitchen is a concept restaurant. We never present it as a real business or a real client,
and it has no reviews, ratings or customer numbers (we don't invent them).

## Honesty rules built into the site
- Orders open WhatsApp to **our studio number** with the message starting `Concept site order:`, and the
  order dialog says so (`ordering` in `src/config/restaurant.ts`).
- The footer says "Concept website designed and built by PrimeCraft Labs. Masala Lane Kitchen is a concept restaurant."
- `robots: noindex`, so it never shows up in Google as a real restaurant.
- No phone number shown.

## What's in it
- Home: photo hero, highlights, most-ordered dishes, "our kitchen" story, photo gallery, how to order, visit + hours
- `/menu/`: full menu with photos, veg/non-veg marks, prices and quantity controls
- Order dialog: review dishes, change quantities, total, then "Send order on WhatsApp"
- `/credits/`: photographer credits (Unsplash)

## Photos (Unsplash, free)
- What to search for each slot: `photos.plan.json` (slot = dish id from menu.ts, or hero/kitchen/interior).
- Picked photos + credits: `src/config/photos.json`, generated by
  `tools/.venv/Scripts/python tools/unsplash_photos.py projects/demo-restaurant --sheet sheet.png`
  (needs `UNSPLASH_ACCESS_KEY` in `jk/.env`; free limit is 50 requests/hour, so about 20 photos/hour).
- Swap a bad photo: `--redo <slot>` (next unused result), `--pick <slot>=N`, or change its query in the plan.
- Photos are hotlinked from images.unsplash.com and credited, as the Unsplash API guidelines require.

## Configuration (change one place, nothing hard-coded)
| What | Where |
|---|---|
| PrimeCraft Labs details (name, WhatsApp, portfolio URL, repo path / basePath) | `jk/brand/brand.json`, then `python jk/brand/sync.py` (writes `src/config/brand.json`; never edit that copy) |
| Studio credit text and "website like this" WhatsApp message | `src/config/studio.ts` |
| Restaurant: name, cuisine, tagline, area, hours, order routing, highlights, story, steps, gallery | `src/config/restaurant.ts` |
| Menu: categories, dishes, prices, veg/non-veg, popular (keep 6 popular for an even grid) | `src/config/menu.ts` |
| Photos | `photos.plan.json` -> `src/config/photos.json` (see above) |
| Colours and fonts | `src/app/globals.css` (tokens) + `src/app/layout.tsx` (fonts) |
| Icons | `src/components/Icon.tsx` |

Only exception: `src/app/icon.svg` (favicon) has its two colours written in, because favicons can't read CSS tokens.

## Run / build / check
```
npm install
npm run dev     # http://localhost:3000/masala-lane-kitchen/
npm run build   # static site in out/
# from jk/ (in Git Bash prefix with MSYS_NO_PATHCONV=1, or the /routes get mangled):
python tools/responsive_check.py --mount /masala-lane-kitchen/=projects/demo-restaurant/out --routes /masala-lane-kitchen/ /masala-lane-kitchen/menu/ /masala-lane-kitchen/credits/
```
Deploys automatically via `.github/workflows/deploy.yml` on push to `main`.

## Turning it into a real client site
In `src/config/restaurant.ts`: real name, area, hours; set `ordering.whatsappUrl` to the restaurant's own
`https://wa.me/<number>`, `messagePrefix: ""` and `note: ""`. Update `menu.ts`, use the client's own photos,
remove the "concept" sentence in the footer (`Chrome.tsx`), and drop `robots: noindex` in `layout.tsx`.
